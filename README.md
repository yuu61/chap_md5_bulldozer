## 法的な注意（抵触しうる法律）

本ツールは、CHAP / SIP Digest 認証の**パスワードを総当たりで復元**するものであり、その前提として**通信のキャプチャ・解析**を伴う。<br>
自分が管理・所有せず、かつ正当な許可も得ていない機器・回線・アカウントに対して使用すると、日本国内では以下の法律に抵触する可能性がある<br>
（以下は代表例であり、これで網羅されるものではない）。

| 法律 | 想定される抵触行為 | 主な罰則（概略） |
| --- | --- | --- |
| **不正アクセス禁止法**（不正アクセス行為の禁止等に関する法律） | 復元したID・パスワードを無断で入力し、アクセス制御された機器・サービスに接続する行為（同法3条）。他人の識別符号を不正に取得・保管・提供する行為（同4〜6条） | 不正アクセス行為: 3年以下の拘禁刑または100万円以下の罰金／識別符号の不正取得等: 1年以下の拘禁刑または50万円以下の罰金 |
| **電気通信事業法** | 他人間の通信を無断で傍受・解析し、その内容（認証情報を含む）を知得・窃用する「通信の秘密」の侵害（同法4条） | 2年以下の拘禁刑または100万円以下の罰金（電気通信事業に従事する者はより重い） |
| **有線電気通信法** | 有線区間での通信の秘密の侵害（同法9条） | 2年以下の拘禁刑または50万円以下の罰金 |
| **電波法** | 無線区間を傍受して得た通信の秘密を窃用する行為（同法59条） | 1年以下の拘禁刑または50万円以下の罰金（業務従事者はより重い） |
| **刑法** | ツール自体の作成・提供・取得・保管が「不正指令電磁的記録に関する罪」（168条の2・168条の3）に問われうる／取得した認証情報の悪用が電子計算機使用詐欺（246条の2）・私電磁的記録不正作出（161条の2）・業務妨害（234条の2）に該当しうる | 罪により異なる（例: 不正指令電磁的記録の作成・提供は3年以下の拘禁刑または50万円以下の罰金） |
| **個人情報保護法** | 復元した認証情報や通信内容が個人情報を含む場合の、不正な手段による取得 | 命令違反等に対する罰則あり |

このほか、

- **民事責任**: 相手方に損害が生じれば、不法行為（民法709条）による損害賠償責任を負いうる。
- **契約違反**: 通信事業者・プロバイダ・クラウド事業者の利用規約（AUP）に違反しうる。
  無断のスキャン／クラッキング目的の利用はほぼ確実に規約違反であり、アカウント停止等の対象。
- **国外での実行**: 本リポジトリの `DEPLOY_EC2.md` のように国外リージョン（例: 米国）で
  実行する場合、実行地の法（米国であれば Computer Fraud and Abuse Act 等）や、対象機器の
  所在国の法も併せて適用されうる。
